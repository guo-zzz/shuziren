# 这个目录放官方抽样语料（不进仓库）

需要放这里的文件：`测试语料-官方抽样.jsonl`

- 来源：赛事方 train 集抽样，由唐应杰整理。
- 用途：只用于团队内部跑情绪实测套件。
- 纪律：**语料本体不进仓库、不对外分享**；初赛 val 集整条留作正式预演，不得提前查看。
- 没放这个文件时，情绪实测套件会自动 SKIP（其它套件照常跑），属正常现象。

放回文件后，到上一级 `demo/` 目录执行：

````bash
node tests/run-tests.mjs --suite emotion
````

> 本文件是这一层唯一允许进仓库的文件（见根目录 `.gitignore`）。
